# Hidden Settings

A small Android TV / Google TV app that opens Settings screens your TV has but doesn't show in its menus, like **Install unknown apps**, **Developer options** and **Usage access**.

## Download

In the Downloader app, enter code **3976204**, or download [Hidden-Settings.apk](https://github.com/Fraction7551/Hidden-Settings/releases/latest/download/Hidden-Settings.apk) directly.

Then open **Hidden Settings** from your apps.
