# Hidden Settings

A small Android TV / Google TV app that opens Settings screens your TV has but doesn't show in its menus, like **Install unknown apps**, **Developer options** and **Usage access**.

## Download

[Hidden-Settings.apk](https://github.com/Fraction7551/Hidden-Settings/releases/latest/download/Hidden-Settings.apk)

Install it with Downloader or any sideloading app, then open **Hidden Settings** from your apps.
